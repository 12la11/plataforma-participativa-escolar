# Portal estudiantil

## Abrir la plataforma

Abre `index.html` directamente en el navegador. El registro y el inicio de sesión funcionan sin servidor: las cuentas se guardan únicamente en el almacenamiento local de ese navegador y dispositivo.

Las secciones personales requieren iniciar sesión. El perfil, las notas, las materias destacadas, las respuestas a encuestas, las sugerencias y las actividades guardadas se asocian a la cuenta activa y no se mezclan con otras cuentas de este navegador.

Al crear una cuenta, la contraseña se guarda como un hash local. Usa una contraseña que no compartas con otros servicios. Los datos solo están en este navegador y dispositivo; si borras los datos del navegador o cambias de dispositivo, perderás el acceso a esa cuenta. Otros usuarios del mismo perfil del navegador podrían acceder a sus datos locales.

La contraseña debe tener entre 8 y 128 caracteres. En Materias, las preguntas y respuestas quedan guardadas solo en la cuenta local activa; no se comparten con otros usuarios. Los puntajes docentes requieren un servidor y no están disponibles en modo local.
